# 42 Examark 1.4.0

Esta release contém a interface revisada e substitui a 1.3.1 como versão recomendada.

## Mudanças

- Nome 42 Examark, interface mais compacta e linguagem objetiva, sem slogans ou frases motivacionais.
- Explicação em português, enunciado original próximo, regras claras, exemplos expansíveis e fontes compactas nos 14 exercícios.
- Gabarito revelado com um clique, duas soluções por exercício e variante: 32 implementações com explicações por linha, comparação e limites.
- Visualização Python da solução escolhida e resultados com diagnóstico principal, esperado e obtido, mantendo todos os testes detalhados.
- Simulado e Progresso simplificados; exercícios nunca tentados não aparecem como falhas.
- Códigos, notas, compreensão, histórico, importação/exportação, atalhos e redimensionamento preservados.
- Inicialização corrigida para criar a pasta de dados anterior quando o aplicativo abre pela primeira vez em um computador novo.
- Verificação automática de linguagem nas telas e nos arquivos de interface efetivamente empacotados: os pacotes não são publicados se contiverem as frases antigas.

## Qual arquivo enviar

Para um amigo com Windows de 64 bits, envie **42-Examark-1.4.0-Windows-x64-Portatil.exe**. Não precisa instalar Node.js ou Python.

Também estão disponíveis instalador Windows, AppImage e tar.gz para Linux x64/ARM64. Use a arquitetura correta; o tar.gz dispensa FUSE.

Os pacotes incluem Python e funcionam offline. Compartilhe apenas o executável ou arquivo original, sem sua pasta pessoal de progresso. A pasta **42 Exam Trainer Dados** foi mantida para compatibilidade com versões anteriores.

## Validação

A publicação depende de todos os testes e builds do GitHub Actions: 40 testes automatizados, 32 soluções em 1.898 casos, 192 rastreamentos de soluções, 949 casos originais, rastreamentos didáticos, interface no Electron e inspeção dos pacotes.

O teste desktop verifica gabaritos, preservação de código, histórico, simulado, interrupção, timeout, persistência e quatro resoluções. Os pacotes Linux x64 são abertos no modo AppImage e no formato extraído. ARM64 é empacotado e inspecionado, sem teste em hardware ARM.

Os executáveis Windows não têm certificado digital. Linux exige glibc e bibliotecas gráficas compatíveis; não há garantia para toda distribuição. O aplicativo é comunitário e não oficial da 42. Os testes locais não garantem aprovação na prova oficial.
